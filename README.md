# Personal Portfolio Website

A modern and responsive personal portfolio website built with HTML and CSS.

## About the Project

This project is a simple personal portfolio website designed to showcase my skills, projects, experience, and contact information.

The main purpose of this project is also to demonstrate a complete Git and GitHub workflow, including commits, branches, pull requests, issues, code reviews, and GitHub Actions.

## Technologies Used

* HTML5
* CSS3
* Git
* GitHub
* GitHub Actions

## Project Structure

```text
website-portfolio/
│
├── index.html
├── style.css
├── README.md
├── .gitignore
│
└── .github/
    └── workflows/
        └── hello.yml
```

## How to Run

No installation or dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/Eng-saacid/my-portfolio-Eng-Saacid.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.
